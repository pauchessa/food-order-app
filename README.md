# Food Order App

A food ordering web application built with React. Users can browse meals, add them to a cart, edit cart items, and submit an order through a checkout form.
This project was built to practice component composition, state management, Context, form handling, HTTP requests, and side effects.

## Features

- Fetch and display meals from the backend
- Add and remove meals from the cart
- Adjust meal quantities
- View the cart and checkout form in modals
- Submit orders with customer information
- Handle loading and error states

## Technologies

- React
- JavaScript
- React Context
- REST API
- CSS
